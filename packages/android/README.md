# Android `<vlc-video>`

Lynx `Behavior` for the `<vlc-video>` tag. No JS framework code.

**Maven Central:** `io.github.carlos-sweb:lynx-vlc-video:0.1.0`

**Use it:** [docs/quick-start.md](../../docs/quick-start.md) then [docs/android-host.md](../../docs/android-host.md).

Public API: [attributes](../../docs/api-attributes.md), [methods](../../docs/api-methods.md), [events](../../docs/api-events.md).

```bash
./gradlew :packages:android:assembleRelease
# after secrets are in ~/.gradle/gradle.properties:
./gradlew :packages:android:publishToMavenCentral
```
